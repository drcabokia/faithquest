Scope: the ordered November 2026 audit on `codex/study-tools-navigation`. The application remains a private test release. These are repository changes, not a deployment or public-launch approval. Existing workspace changes outside the audit are preserved.

Each item receives a focused commit after lint, application type checks, the full unit suite, both builds, and the full demo and isolated-account Playwright suites pass.
