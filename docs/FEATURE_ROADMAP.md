# Feature roadmap

| Stage                  | Deliverables                                                                                                                | Status                                                                                                       |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Foundation             | Planning, strict typed Next.js app, light/dark theme, navigation                                                            | Complete                                                                                                     |
| Demo                   | Full canonical 365-day plan and WEB reader; progress, XP, streaks, six quiz questions, journal, achievements, map, settings | Complete                                                                                                     |
| Database preparation   | Schema/RLS, full canonical reference seeds, command contract, auth plan                                                     | Implemented; embedded PostgreSQL tests pass; hosted application pending                                      |
| Validation             | Lint, types, 52 business/content/database/auth tests, five browser scenarios, production build                              | Passed locally                                                                                               |
| Deployment             | GitHub workflow and Vercel guide                                                                                            | GitHub published; CI passed; Vercel not deployed                                                             |
| Production integration | Google OAuth, Supabase command adapter, transactional RPCs, RLS tests, privacy/export/deletion/backup operations            | Implemented behind disabled flags; hosted OAuth/session/privacy acceptance and production operations pending |
| Editorial expansion    | Chronological/balanced schedules, other canons, more reviewed quizzes, languages                                            | Future                                                                                                       |
| Fellowship             | Opt-in groups, encouraging participation percentages, private notes never shared                                            | Future                                                                                                       |
| Study tools            | Memory verses, explicit grace policy, seven-day challenges, highlights, prayer categories                                   | Future                                                                                                       |
| Optional integrations  | AI with citations/interpretation labels, PWA, push                                                                          | Future; absent/disabled                                                                                      |

AI must never invent verses or blur Scripture and interpretation. It must disclose uncertainty and differing Christian interpretations. Group design must encourage consistency without comparing spiritual maturity. Grace days will need an explicit, tested calendar policy before a claim control is introduced; the demo does not pretend that a grace balance exists.
