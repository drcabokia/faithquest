# Feature roadmap

| Stage | Deliverables | Status at planning |
| --- | --- | --- |
| Foundation | Docs, typed Next.js app, theme, navigation | Starting |
| Demo | Canonical 365 days, reader, progress, XP, streaks, quizzes, journal, achievements, settings | Next |
| Database preparation | SQL, RLS, repository interface, auth plan | Next |
| Validation | Unit tests, lint, type check, production build | Required before handoff |
| Production integration | Google OAuth, Supabase repositories, transactional RPCs, RLS integration tests, backups/deletion | Future; requires accounts and review |
| Editorial expansion | Chronological/balanced plans, more reviewed quizzes, other canons/languages | Future |
| Fellowship | Opt-in groups, participation percentages, private notes never shared | Future |
| Study tools | Memory verses, explicit grace policy, challenges, highlights, prayer categories | Future |
| Optional integrations | AI with citations and interpretation labels, PWA, push | Future; disabled by default |

AI must never invent verses or blur Scripture and interpretation. It must disclose uncertainty and differing Christian interpretations. Group design must encourage consistency without comparing spiritual maturity.
