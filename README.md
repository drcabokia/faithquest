# FaithQuest365

**Read. Discover. Grow in Faith.**

A welcoming 365-day Bible reading companion. Reading missions, thoughtful quizzes, private reflections, and gentle participation rewards help readers return to Scripture. XP represents participation, never spiritual maturity.

## Development

The initial implementation is proceeding through the seven phases in the project brief. See [the project plan](docs/PROJECT_PLAN.md), [architecture](docs/ARCHITECTURE.md), [roadmap](docs/FEATURE_ROADMAP.md), and [database design](docs/DATABASE_DESIGN.md).

Target: Next.js App Router, React, strict TypeScript, Tailwind CSS, accessible shadcn/ui components, Lucide icons, Recharts, and Zod. The first release is an explicitly labelled browser-local demo. Supabase authentication and durable user storage are a separate production integration.

Hosting target: GitHub → Vercel Hobby for personal, non-commercial use, with optional Supabase Free. No paid AI dependency or custom server.
